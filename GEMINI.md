# Global Rules & Guidelines

## Verification & Build
- **Always verify the build and test suite (`flutter analyze`, `flutter test`, and `flutter build windows --debug` or target platform build) before creating any local git commit.**

## Git & Deployment
- **Do not push commits to remote (`git push`) until the user has tested the changes and explicitly requested or approved pushing.**
- Commits may be created locally when helpful, but pushing to origin/remote is strictly gated on user verification and approval.
